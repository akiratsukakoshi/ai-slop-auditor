# AI Slop Auditor

AI生成物にありがちな表現・構造・癖を発見し、作り手が無自覚に採用しているパターンに気づくための「辛口監査官」です。ChatGPTで作成・監査テストを重ねたスキルを、原文のまま配布しています。

## 設計思想

第一の仕事は「良いデザインに直すこと」ではなく、**AI生成パターンの発見**です。フォント、配色、構造、装飾、文章表現、UIなどを観察し、具体的な箇所・観測事実・似ている生成パターン・確信度を示します。

目的に合う、意図的である、品質が高いという理由で、AIっぽい特徴を検出対象から除外しません。まず鑑識結果を残し、その後で人間が「残す／削る／変更する／意図を確認する」を判断します。目的適合の判定は修正の要否に使い、発見を消すためには使いません。

**表面の完成度と意味の密度の落差**も重要な監査観点です。一見精巧でも、細部の文章・図表・UI・背景要素・機能に意味や実体があるかを点検します。見た目からの疑いと、実際に検証できた空虚さを区別します。

## 対応する成果物

- 文章・コラム・メール
- 画像・バナー・チラシ・POP
- スライド
- Webサイト・UI
- アプリ・ツール・コード
- 動画・音声・その他の成果物

完成品を対象にする `quick` が標準です。プロンプトや修正履歴も渡す `deep` では、制作過程の証拠と成果物を照合します。閲覧・実行・音声や動画の確認など、実際に監査できる範囲は利用するAI環境の機能によります。

## ファイル構成

```text
ai-slop-auditor/
├── README.md
└── ai-slop-auditor/
    ├── SKILL.md
    └── references/
        ├── audit-checklists.md
        └── standalone-prompt.md
```

スキル本体は内側の `ai-slop-auditor/` フォルダです。3ファイルの内容と相対配置を保って利用してください。実行スクリプトやAPIキーは含みません。

## インストール方法

### CodexのSkill Installerを使う

`$skill-installer` が利用できるCodexで、次のように依頼します。

```text
$skill-installer install https://github.com/akiratsukakoshi/ai-slop-auditor/tree/main/ai-slop-auditor
```

GitHubのスキルフォルダからインストールする方法は、[OpenAIの公式スキルカタログ](https://github.com/openai/skills)を参照してください。

### スキルフォルダを手動で取得する

1. このリポジトリの **Code → Download ZIP** から取得するか、以下のコマンドでクローンします。
2. `SKILL.md` が直接入っている内側の `ai-slop-auditor/` フォルダを、利用環境が指定するスキル配置先にコピーします。
3. ファイルの取り込み形式・再読み込み手順は、利用環境の案内に従ってください。ZIP取り込みの場合も、このスキルフォルダと `references/` の関係を保ってください。

```sh
git clone https://github.com/akiratsukakoshi/ai-slop-auditor.git
```

利用例：

```text
AI Slop Auditorを使って、添付のスライドを監査してください。
AI生成パターンの発見を優先し、原本は変更しないでください。
```

## プロンプトだけで利用する方法

スキルのインストールができない環境では、[コピペ用プロンプト](ai-slop-auditor/references/standalone-prompt.md)を開き、本文をチャットに貼り付けてください。末尾の「監査対象」に文章を入れるか、画像・ファイル・URLなどを添えます。

これは単独利用向けのプロンプトです。スキル本体の全手順や専門チェックリストが自動的に読み込まれるわけではありません。

## 判定の限界

**AI生成かどうかを断定するツールではありません。** 「AIっぽい特徴」「AI製である証明」「低品質」は別の判断です。一般的なデザイントレンドや人間の表現にも同じ特徴が現れます。外見だけでAI製や特定モデル製と断定しません。

観測・推測・未確認を分け、根拠が弱い場合は確信度を下げます。無理に粗探しせず、見つからなければその旨を述べます。改善案は人間の判断を助ける提案であり、意図的な逸脱や個性を一律に消すものではありません。
